代理设置
这里填写上游 SOCKS5 服务器的实际监听地址，可以是本机、局域网或远端服务器。例如：socks5://192.168.2.222:1186。TunFlow 会直接连接这个地址，出口 IP 由该 SOCKS5 服务器决定，不要求必须使用 127.0.0.1 本地端口。
自动模式会跟随 Windows 当前默认网络；也可以手动固定到某张网卡。
最小化或关闭窗口不会停止 TunFlow；主窗口会隐藏到右下角系统托盘。鼠标悬停托盘图标可查看工作状态。
分流规则
规则按“直连优先 → 代理规则 → 默认策略”判断。当前 TUN 路径稳定支持 IP、CIDR、私网和 GeoIP 规则；域名 / GeoSite 需要进一步接入域名感知层后才会生效。
规则优先级与 x-tunnel 设计保持一致：直连规则先于代理规则。
高级设置
TunFlow 桌面层尽量保持 tun2socks 核心不变，只负责配置、路由和策略。
打包版默认从 EXE 同目录读取 geoip.dat。
下载最新 GeoIP 或 GeoSite 规则文件，更新后重启 TunFlow 生效。
Windows 版本会自动请求管理员权限，并在启动时配置 TUN 默认路由，同时为 SOCKS5 服务器建立直连绕行路由，避免代理回环。
