代理设置
开机启动只负责打开 TunFlow，不会自动启动代理服务；SOCKS5 服务器仍需可用。
分流规则
规则按“直连优先 → 代理规则 → 默认策略”判断。当前 TUN 路径稳定支持 IP、CIDR、私网和 GeoIP 规则；域名 / GeoSite 需要进一步接入域名感知层后才会生效。
规则优先级与 x-tunnel 设计保持一致：直连规则先于代理规则。
高级设置
TunFlow 桌面层尽量保持 tun2socks 核心不变，只负责配置、路由和策略。
打包版默认从 EXE 同目录读取 geoip.dat。
Windows 版本会自动请求管理员权限，并在启动时配置 TUN 默认路由，同时为 SOCKS5 服务器建立直连绕行路由，避免代理回环。
